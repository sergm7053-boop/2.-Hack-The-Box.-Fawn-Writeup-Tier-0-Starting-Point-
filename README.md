--- ## 1. Резюме (Executive Summary)
В ходе планового тестирования на проникновение исследован целевой хост `Fawn` (IP 10.129.29.132) на киберполигоне Hack The Box.
В результате анализа периметра обнаружена критическая уязвимость небезопасной конфигурации службы передачи файлов (Broken Authentication / Anonymous FTP Access). Данный недостаток позволил получить несанкционированный доступ к файловой системе сервера без прохождения легитимной авторизации и успешно эксфильтровать конфиденциальные данные (флаг корневого пользователя).

## 2. Этап разведки и сканирования (Reconnaissance & Scanning)
### 2.1. Проверка сетевой доступности (ICMP Echo)
Перед началом активной фазы сканирования была проведена проверка стабильности сетевого моста до цели с использованием утилиты `ping`:
```ping -c 3 10.129.29.132```
 
**Результат:** `3 packets transmitted, 3 received, 0% packet loss`. Среднее время отклика (RTT) составило ~122 мс, что подтвердило стабильность зашифрованного VPN-туннеля.

### 2.2. Сканирование портов и определение служб (Nmap)
Для детального исследования портов был запущен сетевой сканер `nmap` с флагами глубокого определения версий ПО (`-sV`) и отключением предварительного ICMP-зондирования (`-Pn`) для обхода возможных ограничений брандмауэра:
```sudo nmap -Pn -p 21 -sV 10.129.29.132```
**Результат сканирования:** ```text PORT STATE SERVICE VERSION 21/tcp open ftp vsftpd 3.0.3 Service Info: OS: Unix ```
Сканирование выявило один открытый порт — **21/tcp**, на котором развернута служба **vsFTPd версии 3.0.3**
Операционная система целевого хоста идентифицирована как семейство **Unix**.
